# Prisões Invisíveis: A Escravidão do Século XXI

Site interativo desenvolvido como atividade curricular da faculdade, com o objetivo de refletir sobre os impactos da pressão profissional e acadêmica na saúde mental de jovens | abordando temas como ansiedade, burnout, depressão, vícios e rotina de sobrecarga.

🔗 **[Acessar o site](https://kaike000708.github.io/prisoes-invisiveis-site/)**

---

## 📖 Sobre o projeto

O projeto nasceu como trabalho acadêmico, mas também serve como ambiente de prática de **HTML, CSS e JavaScript puros** (sem frameworks), explorando efeitos visuais, animações e transições entre páginas para criar uma experiência imersiva em torno de um tema sério.

## ✨ Funcionalidades e efeitos

- 🌧️ Animação de chuva em `<canvas>` no fundo da página inicial
- ⌨️ Efeito de texto digitado (typing effect)
- 🎞️ Transições animadas entre páginas
- 📜 Marquee (texto em rolagem contínua) com os temas do site
- 📱 Layout responsivo
- 🎥 Uso de vídeo e imagens para reforçar o impacto visual de cada tema

## 🚀 Rodando localmente

Como é um site estático, basta abrir o `index.html` diretamente no navegador, ou servir a pasta com qualquer servidor local, por exemplo:

```bash
# Python
python -m http.server 8000
```

Depois acesse `http://localhost:8000` no navegador.
